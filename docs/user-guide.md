# User guide

How to use the table page. This guide covers what isn't obvious from the screen; it grows as
features need explaining.

## Keyboard

The table page is made of panels (Actors, Map, Combat, Chat and the rest), docked in groups.
Each group shows one panel at a time behind a strip of tabs.

| Keys                          | What they do                                                                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **F6**                        | Moves to the next panel group: top to bottom, then left to right; floating groups come last. From the header, the first group. |
| **Shift+F6**                  | Moves to the previous panel group. From the header, the last group.                                                            |
| **Tab** from the page's top   | Shows **Skip to panel**, a row of the open panels. Choose one to show it and move into it.                                     |
| **Left** and **Right arrows** | Move along a group's tabs; **Enter** shows the focused tab.                                                                    |
| **Tab** and **Shift+Tab**     | Move through the controls inside a panel.                                                                                      |

Landing in the chat, by F6 or **Skip to panel**, puts you in the message box, ready to type.
Elsewhere you land on the panel itself, and the next **Tab** reaches its first control.

Some browsers and screen readers use F6 themselves, for the address bar. On the table page, F6
moves between panels instead; use **Ctrl+L** (**⌘L** on a Mac) to reach the address bar.

For screen readers, the panels sit in the page's `main` landmark, and each panel is a tab panel named after its tab.
